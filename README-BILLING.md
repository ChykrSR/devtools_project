# บิลค่ารักษา ใบแจ้งหนี้ และใบเสร็จ

## สิ่งที่ปรับในรุ่นนี้

นำตัวกรองและคอลัมน์สถานะออก เพิ่มปุ่มถังขยะถัดจากดูเอกสารให้แอดมิน/เจ้าหน้าที่ พร้อมยืนยันก่อนลบ การลบเป็นการนำออกจากรายการทุกฝ่าย ใบแจ้งหนี้และใบเสร็จที่เกี่ยวข้องจะเปิดผ่าน API ไม่ได้ แต่เก็บบิล ยอดชำระ ใบเสร็จ และผู้ลบ/เวลาลบไว้ในฐานข้อมูล รองรับการลบทั้งบิลที่ยังไม่ชำระและชำระแล้ว ไม่ต้องเพิ่มตารางหรือรัน migration ใหม่


การโอนเงินกลับเป็นแบบไม่ต้องระบุบัญชีหรือแนบ QR แล้ว เลือกโอนเงินและบันทึกยอด/หมายเหตุอ้างอิงตามเดิม ข้อมูลบัญชีในบิลเก่าไม่ได้ลบออกจากฐานข้อมูล แต่หน้าจอใบแจ้งหนี้จะแสดงเพียงวิธีชำระเงิน


- ผู้ดูแล/เจ้าหน้าที่กด “ออกและส่งใบแจ้งหนี้ให้เจ้าของสัตว์เลี้ยง” ใบแจ้งหนี้จะปรากฏในบัญชีของเจ้าของที่เลือกทันที เจ้าของเข้าส่วนบิลเพื่อเปิดดูและพิมพ์ได้
- การส่งเป็นการส่งภายในระบบ ไม่มีการส่งอีเมล SMS หรือแจ้งเตือนภายนอก
- ใบแจ้งหนี้จัดรูปแบบตามภาพอ้างอิง: ข้อมูลคลินิก เลขเอกสาร วันที่ ยอดเงินเป็นตัวอักษร รายการค่ารักษา ส่วนข้อมูลผู้ชำระและวิธีชำระเงิน ไม่มีโลโก้ธนาคาร บาร์โค้ด หรือ QR อัตโนมัติ
- เงินสดและบัตรคงการบันทึกชำระเดิม ไม่มีช่องบัญชีหรือ QR
- นำข้อความโหมดทดลองออกจากหน้าจอและเอกสาร และนำปุ่มรายการตัวอย่าง/ชุด Tester ออกจากไฟล์ส่งมอบ
- การแบ่งชำระ ใบเสร็จแต่ละครั้ง สิทธิ์เข้าถึง การป้องกันยอดเกิน และคำขอซ้ำยังทำงานตามเดิม

## ติดตั้งหรืออัปเดตด้วย Docker

สำรองโค้ดและฐานข้อมูลก่อนอัปเดต แล้วคัดลอกไฟล์จาก ZIP ให้ตรงโครงสร้าง root/public ของโปรเจค จากนั้นรัน:

```sh
docker compose up -d --build
```

ไม่ต้องเรียก `migrate-billing.js` อีกต่อไป เมื่อเซิร์ฟเวอร์เริ่มทำงาน จะสร้างเฉพาะตาราง billing ที่ยังไม่มีโดยอัตโนมัติจากส่วน `BEGIN BILLING SCHEMA` ใน `init.sql`

- ฐานข้อมูลใหม่: MySQL ใช้ init.sql ตาม Docker Compose เดิม
- ฐานข้อมูลที่ใช้อยู่: เซิร์ฟเวอร์อ่านเฉพาะส่วน billing ไม่รัน seed / ALTER ของระบบเดิมซ้ำ
- ตาราง/ข้อมูลบิลจากรุ่นก่อนยังใช้ได้ รูปและบัญชีเก็บใน snapshot JSON เดิม ไม่ต้องเพิ่มคอลัมน์
- ไม่ต้องลบ volume และไม่ควรใช้ `docker compose down -v`
- ถ้าเพิ่มไฟล์ลงโปรเจครุ่นก่อนเอง ให้ลบโฟลเดอร์ `test/`, `scripts/migrate-billing.js` และ `migrations/001_billing.sql` ที่เป็นของส่วนบิลรุ่นก่อน หากไม่มีงานอื่นใช้อยู่
- หากเตรียมตารางไม่สำเร็จ ส่วนบิลตอบ 503 แต่ route เดิมยังเริ่มได้ ตรวจสิทธิ์ CREATE ของบัญชี DB และ config ฐานข้อมูลแล้ว restart web

เปิด `http://localhost:3000/billing.html` หรือเมนูบิลบน Dashboard ใช้บัญชีเดิมยืนยันตัวตน

## รันโดยไม่ใช้ Docker

ตั้ง DB_HOST, DB_USER, DB_PASSWORD, DB_NAME ให้ตรงกับ MySQL ของคุณ แล้วรัน:

```sh
npm ci
node server.js
```

ค่า DB_HOST เริ่มต้นคือ `db` ตาม Docker Compose ถ้าใช้ MySQL บนเครื่องเองให้ตั้งเป็น host จริง เช่น localhost

## วิธีใช้งาน

1. ผู้ดูแล/เจ้าหน้าที่เข้าส่วนบิล เลือกสัตว์เลี้ยงและเจ้าของ ใส่รายการ ราคา จำนวน และส่วนลด
2. เลือกวิธีชำระเงินได้ตามเดิม การโอนเงินไม่ต้องกรอกข้อมูลบัญชีหรือแนบ QR
3. กดออกและส่งใบแจ้งหนี้ ระบบบันทึกเวลาและผู้รับไว้กับเอกสาร
4. เจ้าของสัตว์เข้าส่วนบิล เห็นใบแจ้งหนี้ของตนพร้อมวิธีชำระเงินที่เลือก และพิมพ์/บันทึก PDF ได้
5. เมื่อผู้ดูแลตรวจสอบการรับชำระแล้ว บันทึกยอดชำระตามเดิม ระบบออกใบเสร็จแต่ละครั้ง รองรับแบ่งชำระ

## ขอบเขตการชำระเงิน

การรับโอนเป็นการชำระภายนอกระบบ ระบบยังไม่เชื่อมธนาคารหรือ gateway ไม่ตรวจยอดโอนอัตโนมัติ และไม่ทำธุรกรรมบัตร การนำข้อความทดลองออกไม่ใช่การเพิ่มบริการชำระออนไลน์ ผู้ดูแลต้องตรวจสอบก่อนยืนยันบันทึกยอด

## ข้อมูลและสิทธิ์

- เงินคำนวณด้วยจำนวนเต็มหน่วยสตางค์ สูงสุด 1,000,000 บาทก่อนส่วนลดต่อบิล
- เจ้าของสัตว์เห็นเฉพาะเอกสารของตนเอง เจ้าหน้าที่/แอดมินออกบิลและบันทึกชำระได้ สิทธิ์ vet คงเดิม
- ไม่เปิดช่องทางแก้/ยกเลิกบิล คืนเงิน หรือคำนวณ VAT การลบออกจากประวัติไม่ใช่การคืนเงิน
- บิลเก่าที่ยังไม่มีรายละเอียดบัญชียังเปิดได้
- เซสชันส่วนบิลอายุ 1 ชั่วโมง เก็บในหน่วยความจำเซิร์ฟเวอร์ restart แล้วต้องยืนยันตัวตนใหม่
- ระบบ authentication เดิมของโปรเจคยังมีรหัสผ่าน plaintext และ API เดิมที่ไม่ตรวจสิทธิ์ ต้องแก้ทั้งระบบก่อนเผยแพร่รับข้อมูลลูกค้าจริง

## ไฟล์สำคัญ

- `server.js`: JSON limit เฉพาะบิล, เตรียมตารางอัตโนมัติ และ mount API
- `init.sql`: schema เดิม และส่วน billing ที่มี marker แยกชัดเจน
- `lib/billing-schema.js`: เรียกเฉพาะ CREATE TABLE IF NOT EXISTS ของส่วน billing
- `lib/billing-values.js`: ตรวจรายการ เงิน และวิธีชำระเงิน
- `routes/billing.js`: สิทธิ์ บันทึก snapshot/ผู้รับ/เวลา และ transaction ชำระเงิน
- `public/billing.html`, `billing.js`, `billing.css`, `billing-fonts/`: หน้าจอและเอกสารภาษาไทย
- `public/dashboard.html`: เมนูเปิดส่วนบิล
- `package.json`: นำ placeholder npm test เดิมออก dependencies ไม่เพิ่ม

## การตรวจสอบที่ทำ

ตรวจ API และหน้าจอด้วยฐานข้อมูลจำลอง: สิทธิ์เจ้าของ/ผู้ดูแล ออกบิลแบบโอนโดยไม่ต้องระบุบัญชีหรือ QR การแบ่งชำระ ใบเสร็จ และพิมพ์ PDF ชุดตรวจสอบไม่ได้รวมใน ZIP ตามที่ขอ ยังต้องตรวจการสร้างตารางและ transaction บน MySQL 8 จริงของคุณหลังติดตั้ง

ตรวจการลบเพิ่มเติมแล้ว: API 12 ชุดผ่าน รวมสิทธิ์ ลบซ้ำ ไม่ให้เปิดเอกสาร/ชำระหลังลบ และ rollback เมื่อบันทึกไม่สำเร็จ ตรวจ DOM ของหน้าจอผ่านสำหรับการยกเลิกยืนยัน ข้อผิดพลาดจากเซิร์ฟเวอร์ การรีเฟรชรายการ และปุ่มตามสิทธิ์ ชุดตรวจไม่รวมใน ZIP
