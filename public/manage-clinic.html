UC-11 REST API Reference & Integration Guide

GET /api/users

ดึงรายการผู้ใช้ทั้งหมด รองรับ Query Params: ?role=vet&search=somchai

POST /api/users

เพิ่มผู้ใช้ใหม่โดย Admin (Body: { full_name, email, password, phone, role })

PUT /api/users/:id

แก้ไขข้อมูลผู้ใช้ หรือปรับสถานะเปิด/ปิดการใช้งาน (is_active: 1/0)

GET /api/clinic | PUT /api/clinic

ดึงและอัปเดตข้อมูลคลินิก (ชื่อ, เบอร์โทร, อีเมล, เลขประจำตัวผู้เสียภาษี, เวลาทำการ, ที่อยู่)

JSON Response Standard Format:

{
  "success": true,
  "message": "User active status updated successfully",
  "data": { "id": 2, "is_active": 1 }
}
